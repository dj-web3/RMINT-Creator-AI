# Recipe Workflow Canvas — Build Spec

A simple, self-contained flowchart editor (FigJam/Miro basics) for designing a recipe workflow. Pure HTML/CSS/vanilla JS. No libraries.

## Goal

Replace a static list of recipe steps with a free-form flowchart canvas:

- **Start** and **End** sentinel nodes bookend the flow
- **Process nodes** in between represent recipe steps
- Click a node → modal opens to edit its fields
- Drag a node → repositions it; arrows follow live
- Drag a node's edge handle to another node → creates a connection arrow
- Click a connection arrow → deletes it
- ✕ on a node → deletes it and all its connections
- "+ Add Step" → adds a new node to the canvas

Edits on the canvas sync into the rest of the app (timeline, guide cards, plan).

---

## Data Model

Single global `appState` object. Everything renders from it.

```js
const appState = {
  selectedPlanStep: null,
  editingNodeId: null,                    // id of node being edited in modal
  sharedDish: {
    ingredients: [
      { name: 'Chicken', quantity: '800g' },
      // ...
    ],
    methodology: [                        // editable process nodes
      {
        id: '1',
        title: 'Chicken Marination',
        chefs: ['SOUS', 'STATION'],       // any of SOUS/STATION/JUNIOR/TRAINEE
        ingredients: ['Chicken', 'Yogurt'],
        duration: '45m',
        startTime: '07:00',
        process: 'Marinating',
        x: 220, y: 240                    // position on canvas in px
      },
      // ...
    ],
    flowNodes: [                          // sentinel nodes (start/end only)
      { id: '_start', type: 'start', label: 'Start', x: 60,  y: 264 },
      { id: '_end',   type: 'end',   label: 'End',   x: 980, y: 264 }
    ],
    connections: [                        // directed edges
      { from: '_start', to: '1' },
      { from: '1',      to: '2' },
      { from: '2',      to: '3' },
      { from: '3',      to: '_end' }
    ]
  }
};
```

**Node id conventions**
- Process nodes: any unique string (we use `String(Date.now())` for new ones)
- Start: `'_start'`, End: `'_end'`
- All ids appear as `data-node-id` attributes on rendered DOM

**Why two arrays (methodology vs flowNodes)?**
Methodology entries carry recipe data and are consumed by the timeline/guide/plan views. flowNodes are visual-only sentinels. Keeping them separate means the other views can iterate `methodology` directly without filtering.

### State globals

```js
let _flowDrag = null;   // { nodeId, startX, startY, origX, origY, moved }

```

`_flowDrag` tracks an in-progress node drag. `_connDrag` tracks an in-progress connection drag from a handle.

### Helpers

```js
function findFlowNode(id) {
  const m = appState.sharedDish.methodology.find(s => s.id === id);
  if (m) return m;
  return appState.sharedDish.flowNodes.find(n => n.id === id);
}
```

### Render

```js
function renderCanvas() {
  const meth = appState.sharedDish.methodology;
  const fn   = appState.sharedDish.flowNodes;
  const nodeHtml = [
    ...meth.map(s => renderFlowNode({ ...s, _type: 'process' })),
    ...fn  .map(n => renderFlowNode({ ...n, _type: n.type }))
  ].join('');
  const hint = `<div class="flow-hint">Click node to edit • Drag node to move • Drag orange dot to connect • Click line to remove</div>`;
  document.getElementById('canvas-nodes').innerHTML =
    `<div class="flow-canvas" id="flow-canvas">
       <svg class="flow-svg" id="flow-svg"></svg>
       ${nodeHtml}
       ${hint}
     </div>`;
  const canvas = document.getElementById('flow-canvas');
  if (canvas) {
    canvas.addEventListener('mousemove', onFlowMouseMove);
    canvas.addEventListener('mouseup',   onFlowMouseUp);
  }
  drawFlowEdges();
}

function renderFlowNode(n) {
  if (n._type === 'start' || n._type === 'end') {
    const hCls = n._type === 'start' ? 'r' : 'l';
    return `<div class="flow-node ${n._type}" data-node-id="${n.id}"
                 style="left:${n.x}px;top:${n.y}px"
                 onmousedown="onNodeMouseDown(event,'${n.id}')">
              ${n.label}
              <div class="flow-handle ${hCls}" onmousedown="onHandleMouseDown(event,'${n.id}')"></div>
            </div>`;
  }
  const chips = (n.chefs || []).map(c => `<span class="flow-node-chip">${c}</span>`).join('');
  const meta  = [n.process, n.duration, n.startTime].filter(Boolean).join(' • ');
  return `<div class="flow-node process" data-node-id="${n.id}"
               style="left:${n.x}px;top:${n.y}px"
               onmousedown="onNodeMouseDown(event,'${n.id}')">
            <div class="flow-node-title">${n.title || 'Untitled'}</div>
            ${meta  ? `<div class="flow-node-meta">${meta}</div>` : ''}
            ${chips ? `<div class="flow-node-chips">${chips}</div>` : ''}
            <button class="flow-node-delete"
                    onmousedown="event.stopPropagation()"
                    onclick="deleteFlowNode(event,'${n.id}')">✕</button>
            <div class="flow-handle t" onmousedown="onHandleMouseDown(event,'${n.id}')"></div>
            <div class="flow-handle r" onmousedown="onHandleMouseDown(event,'${n.id}')"></div>
            <div class="flow-handle b" onmousedown="onHandleMouseDown(event,'${n.id}')"></div>
            <div class="flow-handle l" onmousedown="onHandleMouseDown(event,'${n.id}')"></div>
          </div>`;
}
```

### Drawing edges (SVG cubic Bézier)

Given a `from` node rect and a `to` node rect, find the point on each rect's edge along the line connecting their centers, then draw a horizontal-tangent cubic Bézier between those points.

```js
function edgePoint(fromEl, toEl) {
  const fcx = fromEl.offsetLeft + fromEl.offsetWidth  / 2;
  const fcy = fromEl.offsetTop  + fromEl.offsetHeight / 2;
  const tcx = toEl  .offsetLeft + toEl  .offsetWidth  / 2;
  const tcy = toEl  .offsetTop  + toEl  .offsetHeight / 2;
  const dx = tcx - fcx, dy = tcy - fcy;
  if (dx === 0 && dy === 0) return { x: fcx, y: fcy };
  const w  = fromEl.offsetWidth  / 2;
  const h  = fromEl.offsetHeight / 2;
  const ax = Math.abs(dx) || 0.01;
  const ay = Math.abs(dy) || 0.01;
  const s  = (ax / w > ay / h) ? w / ax : h / ay;
  return { x: fcx + dx * s, y: fcy + dy * s };
}

function drawFlowEdges() {
  const svg    = document.getElementById('flow-svg');
  const canvas = document.getElementById('flow-canvas');
  if (!svg || !canvas) return;

  const w = Math.max(canvas.scrollWidth,  canvas.clientWidth);
  const h = Math.max(canvas.scrollHeight, canvas.clientHeight);
  svg.setAttribute('width', w);
  svg.setAttribute('height', h);
  svg.style.width  = w + 'px';
  svg.style.height = h + 'px';

  const defs = `<defs>
    <marker id="ah" markerWidth="10" markerHeight="8" refX="9" refY="4" orient="auto">
      <polygon points="0 0,10 4,0 8" fill="#87867F"/>
    </marker>
  </defs>`;

  const paths = appState.sharedDish.connections.map(c => {
    const fromEl = canvas.querySelector(`[data-node-id="${c.from}"]`);
    const toEl   = canvas.querySelector(`[data-node-id="${c.to}"]`);
    if (!fromEl || !toEl) return '';
    const ff = edgePoint(fromEl, toEl);
    const tt = edgePoint(toEl,   fromEl);
    const dxV = Math.max(Math.abs(tt.x - ff.x) * 0.5, 40);
    const d = `M${ff.x},${ff.y} C${ff.x+dxV},${ff.y} ${tt.x-dxV},${tt.y} ${tt.x},${tt.y}`;
    return `<path class="flow-edge" d="${d}"
                  stroke="#87867F" stroke-width="2" fill="none"
                  marker-end="url(#ah)"
                  onclick="removeFlowConnection(event,'${c.from}','${c.to}')">
              <title>Click to remove</title>
            </path>`;
  }).join('');

  const tempLine = _connDrag
    ? `<path d="${_connDrag.tempPath}" stroke="#D97757" stroke-width="2" stroke-dasharray="6,4" fill="none" />`
    : '';

  svg.innerHTML = defs + paths + tempLine;
}
```

### Node drag (mousedown on node body → mousemove → mouseup)

```js
function onNodeMouseDown(e, id) {
  // Ignore clicks on handles / delete button — they have their own handlers
  if (e.target.classList.contains('flow-handle'))       return;
  if (e.target.classList.contains('flow-node-delete'))  return;
  e.preventDefault();
  const node = findFlowNode(id);
  if (!node) return;
  _flowDrag = {
    nodeId: id,
    startX: e.clientX, startY: e.clientY,
    origX:  node.x,    origY:  node.y,
    moved: false
  };
}

function onFlowMouseMove(e) {
  if (_flowDrag) {
    const dx = e.clientX - _flowDrag.startX;
    const dy = e.clientY - _flowDrag.startY;
    if (Math.abs(dx) > 3 || Math.abs(dy) > 3) _flowDrag.moved = true;
    const node = findFlowNode(_flowDrag.nodeId); if (!node) return;
    node.x = Math.max(0, _flowDrag.origX + dx);
    node.y = Math.max(0, _flowDrag.origY + dy);
    const el = document.querySelector(`[data-node-id="${_flowDrag.nodeId}"]`);
    if (el) {
      el.style.left = node.x + 'px';
      el.style.top  = node.y + 'px';
      el.classList.add('dragging');
    }
    drawFlowEdges();
  } else if (_connDrag) {
    const canvas = document.getElementById('flow-canvas');
    const rect   = canvas.getBoundingClientRect();
    const tx = e.clientX - rect.left + canvas.scrollLeft;
    const ty = e.clientY - rect.top  + canvas.scrollTop;
    const sx = _connDrag.startX, sy = _connDrag.startY;
    const dxV = Math.max(Math.abs(tx - sx) * 0.5, 40);
    _connDrag.tempPath = `M${sx},${sy} C${sx+dxV},${sy} ${tx-dxV},${ty} ${tx},${ty}`;
    drawFlowEdges();
  }
}

function onFlowMouseUp(e) {
  // End a node drag — if it didn't actually move, treat as a click → open editor
  if (_flowDrag) {
    const el = document.querySelector(`[data-node-id="${_flowDrag.nodeId}"]`);
    if (el) el.classList.remove('dragging');
    const wasMoved = _flowDrag.moved, id = _flowDrag.nodeId;
    _flowDrag = null;
    if (!wasMoved) openNodeEditor(id);
  }
  // End a connection drag — if mouseup landed on another node, create connection
  if (_connDrag) {
    const target  = document.elementFromPoint(e.clientX, e.clientY);
    const nodeEl  = target ? target.closest('.flow-node') : null;
    if (nodeEl) {
      const toId   = nodeEl.dataset.nodeId;
      const fromId = _connDrag.fromId;
      const exists = appState.sharedDish.connections.some(c => c.from === fromId && c.to === toId);
      if (fromId !== toId && !exists) {
        appState.sharedDish.connections.push({ from: fromId, to: toId });
      }
    }
    _connDrag = null;
    drawFlowEdges();
  }
}
```

**Click-vs-drag trick:** The same mousedown starts a potential drag. If the mouse moves > 3px, mark `moved=true`. On mouseup, if it never moved, treat it as a click → open the editor. This way "click to edit" and "drag to move" share one gesture.

### Connection drag (mousedown on handle → mousemove → mouseup on target)

```js
function onHandleMouseDown(e, id) {
  e.preventDefault();
  e.stopPropagation();    // don't also start a node drag
  const canvas = document.getElementById('flow-canvas');
  const rect   = canvas.getBoundingClientRect();
  const hRect  = e.target.getBoundingClientRect();
  const sx = hRect.left + hRect.width  / 2 - rect.left + canvas.scrollLeft;
  const sy = hRect.top  + hRect.height / 2 - rect.top  + canvas.scrollTop;
  _connDrag = {
    fromId: id,
    startX: sx, startY: sy,
    tempPath: `M${sx},${sy} L${sx},${sy}`
  };
}
```

The temp dashed line is redrawn by `drawFlowEdges()` on every mousemove tick.

### Editor modal

```js
function openNodeEditor(id) {
  const node = findFlowNode(id);
  if (!node || node.type === 'start' || node.type === 'end') return;
  appState.editingNodeId = id;
  document.getElementById('editor-title')      .value = node.title       || '';
  document.getElementById('editor-process')    .value = node.process     || '';
  document.getElementById('editor-duration')   .value = node.duration    || '';
  document.getElementById('editor-starttime')  .value = node.startTime   || '';
  document.getElementById('editor-ingredients').value = (node.ingredients || []).join(', ');
  document.querySelectorAll('.editor-chef-btn').forEach(btn => {
    btn.classList.toggle('active', (node.chefs || []).includes(btn.dataset.chef));
  });
  document.getElementById('node-editor-overlay').classList.add('open');
}

function saveNodeEditor() {
  const id = appState.editingNodeId; if (!id) return;
  const node = appState.sharedDish.methodology.find(s => s.id === id); if (!node) return;
  node.title       = document.getElementById('editor-title').value;
  node.process     = document.getElementById('editor-process').value;
  node.duration    = document.getElementById('editor-duration').value;
  node.startTime   = document.getElementById('editor-starttime').value;
  node.ingredients = document.getElementById('editor-ingredients').value
                      .split(',').map(s => s.trim()).filter(Boolean);
```

### Add / delete

```js
function addStep() {
  const id  = String(Date.now());
  const cnt = appState.sharedDish.methodology.length;
  appState.sharedDish.methodology.push({
    id, title:'New Step', process:'Prep',
    duration:'15m', startTime:'10:00',
    chefs:[], ingredients:[],
    x: 200 + (cnt % 4) * 220,            // simple grid layout for new nodes
    y: 420 + Math.floor(cnt / 4) * 150
  });
  sync();
}

function deleteFlowNode(e, id) {
  e.stopPropagation();
  const idx = appState.sharedDish.methodology.findIndex(s => s.id === id);
  if (idx === -1) return;                                  // can't delete start/end
  appState.sharedDish.methodology.splice(idx, 1);
  appState.sharedDish.connections =
    appState.sharedDish.connections.filter(c => c.from !== id && c.to !== id);
  sync();
}

function removeFlowConnection(e, from, to) {
  e.stopPropagation();
  appState.sharedDish.connections =
    appState.sharedDish.connections.filter(c => !(c.from === from && c.to === to));
  drawFlowEdges();
}
```

### Sync across views

A single `sync()` re-renders every view so canvas edits propagate to timeline / guide / plan.

```js
function sync() {
  renderIngredients();
  renderCanvas();
  renderMethodology();   // can be a no-op if there's no separate methodology view
  renderGuide();
  renderTimeline();
  renderClockCards();
  renderClockView();
}

// Call once on load
sync();
```

The other render functions just iterate `appState.sharedDish.methodology` directly — start/end sentinels live in `flowNodes`, so they never appear in the timeline or guide.

## Gotchas

- **SVG sits behind nodes.** Container has `pointer-events:none`; only `path.flow-edge` opts back in via `pointer-events:stroke`. Without this, the SVG layer would swallow clicks meant for nodes.
- **Title / meta / chips need `pointer-events:none`.** Otherwise they intercept mousedown and break drag/click detection on the parent node.
- **Stop propagation on handle and delete button.** Handles set `e.stopPropagation()` in their own mousedown so they don't also start a node drag. The delete button uses `onmousedown="event.stopPropagation()"` plus `onclick=` so the click fires cleanly.
- **Click vs drag uses a 3px threshold.** If pointer moves ≤3px between mousedown and mouseup, treat it as a click. Tune to taste.
- **`document.elementFromPoint` for drop detection.** When the connection drag ends, find what's under the cursor and walk up to the nearest `.flow-node` to determine the target.
- **Sentinel nodes can't be edited or deleted.** Guard with `if (node.type === 'start' || node.type === 'end') return;` in `openNodeEditor`. `deleteFlowNode` only touches `methodology`, so start/end are immune.
- **Coordinates are page-relative on mousedown, canvas-relative for SVG drawing.** Convert with `e.clientX - rect.left + canvas.scrollLeft`.
- **Re-render vs partial update.** Full `sync()` rebuilds DOM (loses drag state). For cheap visual-only changes (deleting a connection, drawing the temp line during drag), call `drawFlowEdges()` directly — it only mutates `#flow-svg`'s `innerHTML`.
